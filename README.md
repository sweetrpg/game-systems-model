Was a Swift shared-model library for game systems. `gamesystems-api` was rebuilt as a Go service
and owns its own models directly rather than sharing a library - see `sweetrpg/platform`'s
`openspec/changes/game-systems-service` for the full design, and `sweetrpg/gamesystems-api` for
the current implementation.
